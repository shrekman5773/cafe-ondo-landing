# 카페 온도 (Cafe Ondo) 랜딩페이지

가상의 카페 "카페 온도"를 위한 간단한 1페이지 랜딩페이지입니다. 별도 빌드 도구 없이 순수 HTML/CSS로 작성되어 브라우저에서 바로 열어볼 수 있습니다.

## 미리보기

`index.html`을 브라우저로 열면 됩니다.

```bash
open index.html
```

## 구성

- `index.html` — 페이지 구조 및 콘텐츠 (히어로, 소개, 메뉴, 오시는 길, 푸터)
- `style.css` — 스타일 (반응형, 웜톤 브라운/크림 컬러 팔레트)

## 섹션

| 섹션 | 내용 |
|---|---|
| Hero | 카페 대표 문구 + 메뉴 보기 CTA |
| 소개 | 원두, 공간, 시간을 강조하는 3가지 특징 |
| 메뉴 | 시그니처 라떼, 핸드드립, 아메리카노 등 6종 |
| 오시는 길 | 주소, 영업시간, 전화번호 |
| 푸터 | 연락처 및 저작권 표기 |

## 커스터마이징

카페 이름, 메뉴, 주소 등은 `index.html` 내 텍스트를 직접 수정하면 되고, 색상 팔레트는 `style.css` 상단의 `:root` 변수(`--cream`, `--brown`, `--accent` 등)를 바꾸면 전체 톤이 함께 바뀝니다.
